StackPlanner — 以 Memory 为核心的神经符号融合

01 / 11

让智能体既能组织复杂执行，也能从执行中学习。

StackPlanner 面向多场景、多工具与多 Agent 参与的复杂任务，将显式的状态组织与模型策略学习结合起来。我们以 Memory 管理任务状态、执行轨迹和反馈经验，研究系统如何调整行动、组织协作，并将已有工作与经验用于后续任务。

自调节

依据状态调整行动，反思并恢复执行。

高组织

协调 Agent、工具与证据，适应需求变化。

自进化

复用与更新经验，持续改进任务求解。

01

整体思想：符号组织执行，神经学习策略

Harness 决定状态如何表示、任务怎样分工，以及执行如何继续；模型策略决定何时检索、反思、回退或委派。两侧共享执行中产生的信息，使显式机制与学习能力相互支撑。

这里包含两种更新：离线训练改进模型参数与决策策略，在线经验演化更新外部记忆内容。GitHarness 和 GenMem 已在各自工作中结合 Harness 与策略学习；将全部能力纳入统一系统，是持续推进的整合方向。

02

系统架构：StackPlanner 2.0 如何完成任务

中枢依据任务状态选择动作，通过 A2A 接口委派子任务；子 Agent 调用工具并返回观察与产物。中枢据此汇总、反思、继续执行或请求用户补充，DeerFlow2 支撑过程保存与恢复。

方法发展 / 训练支持研究问题关联

Harness 侧由栈式工作记忆推进到分层协作和大纲证据组织；策略学习侧由记忆动作推进到全局反思，再到复杂 Harness 训练。

GitHarness 将需求版本与 Git Agent 策略结合，支持动态需求下的持续协作；GenMem 将经验机制与策略学习结合，使执行经验能够被检索、复用和持续更新。

Memory 体系：工作记忆与经验记忆 ＋

工作记忆保存当前求解与交互的活动信息；经验记忆保存历史积累的可复用信息。单 / 多智能体描述记忆的组织空间。
